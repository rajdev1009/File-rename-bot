3. Environment Variables tab mein set karo:
   API_ID       = your_api_id
   API_HASH     = your_api_hash
   BOT_TOKEN    = your_bot_token
   CHANNEL_ID   = -1001234567890

4. Persistent Volume mount karo:
   /app/tmp_raj_dev  (temp files)
   /app/session      (Telethon session — zaroori hai!)
